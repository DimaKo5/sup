# Работа 28. Безопасность

| Проверка | Реализация |
|---|---|
| Пароли | PBKDF2, индивидуальная соль и сравнение FixedTimeEquals |
| Ключ JWT | Для локального профиля создаётся случайный ключ на время жизни процесса. Для остальных окружений обязателен Jwt:Key |
| Токен | Подпись HMAC-SHA256, проверка получателя, издателя и срока действия |
| Локальный HTTP | Профиль Visual Studio и автономный выпуск слушают localhost |
| Ограничение входа | Пять попыток в минуту по умолчанию |
| Роли | Контроль маршрутов и проверка владельца обращения на сервере |
| Журнал | Токены и пароли в записи входа не включаются |
| Зависимости | NuGet Audit и dotnet package list --vulnerable --include-transitive |

Автоматическое заполнение пустой базы рассчитано на учебный запуск. База, локальные журналы и настройки пользователя исключены из Git.
