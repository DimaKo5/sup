# Работа 27. Тестирование совместимости

| Окружение | Проверка | Результат |
|---|---|---|
| .NET 10 (VS 2026) | Сборка, тесты, запуск | Совместимо |
| .NET 8 (VS 2022) | Замена net10.0 → net8.0 и пакетов на 8.x | Совместимо согласно методичке |
| Масштаб экрана 125 % / 150 % | MainWindow (MinWidth 960, MinHeight 480) | Элементы не перекрываются |
| Русские региональные настройки | Даты и число с разделителем разрядов | Переопределение LanguageProperty |
| Английские региональные настройки | Файлы обмена | InvariantCulture |
| Обычная учётная запись | Журнал клиента | %LOCALAPPDATA%, права есть |
| Публикация без SDK | `dotnet publish` | Самостоятельный клиент запускается |
