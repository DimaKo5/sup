# Работа 24. Инспекция кода

На локальной сверке проверены правила переходов, объектный доступ техника, журнал, обмен данными и запуск чистой копии. В процессе исправлены обязательная подготовка JWT для локального запуска, зависимость проверок FlaUI от жёстко указанного пути, преждевременный учёт телефона отклонённой строки CSV и экспорт дат без обозначения UTC. Аудит зависимостей повторён после обновления EF Core, средств разработки EF и пакетов ASP.NET Core.

Взаимная рецензия и протокол замечаний к проекту партнёра ожидают участия партнёра.
