# Работа 19. Выявление ошибок системных компонентов

| Сценарий сбоя | Как воспроизвести | Признак | Причина | Исправление / защита |
|---|---|---|---|---|
| Сервер недоступен | Остановить Api, нажать «Найти» | «Не удалось подключиться…» | HttpRequestException | Ui.RunSafeAsync |
| Таймаут сервера | Замедлить ответ Api | «Сервер не ответил за 15 секунд» | TaskCanceledException | Таймаут HttpClient 15 с |
| Сеанс истёк | Установить ExpiresMinutes=1 | «Сеанс истёк…» | 401 | ApiException + SetToken |
| Недостаточно прав | Войти technician1, создать сотрудника | 403 | Роль Technician | [Authorize(Roles)] |
| Конфликт БД | Две регистрации одного телефона | 409 | UNIQUE + DbUpdateException | GlobalExceptionHandler |
| Порт занят | Запустить второй Api | Address already in use | Порт 5006 | Остановить процесс / сменить порт |
| Ключ JWT короткий | Запустить вне локального профиля с ключом короче 32 символов | Ошибка запуска | jwt.Key.Length < 32 | Задать ключ для внешней конфигурации |
| Файл БД занят | Отладка во время миграции | MSB3027 | DLL/DB заблокированы | Shift+F5 |

Проверка работоспособности: `GET /health` (работа 19) и `IsServerHealthyAsync` в клиенте.
